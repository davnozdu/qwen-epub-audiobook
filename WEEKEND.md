# Комплект аудиокниг для macOS / M2 Pro

1. Положите EPUB в `books` или приготовьте полный путь к нему.
2. Двойной клик по `START.command` — вся книга. `START-5MIN.command` — примерно
   пять минут с начала, по целым абзацам. Для короткого теста роли определяются
   только по выбранному фрагменту, не по всей книге.
3. Введите имя EPUB (например `Моя книга.epub`) или перетащите файл в Terminal.
4. Укажите папку для результатов. Enter — `results` рядом с запускальщиком.
5. На вопрос облачной LLM: Enter/Y и скрытый ввод ключа; N/«нет» — без облака.

**N отключает только проверку ударений через LLM, не многоголосность.**
Роли и отдельные голоса сохраняются. Для новой книги роли всё равно нужно
определить: сейчас этот этап использует Ollama. Можно использовать тот же ключ
при Y, отдельный ключ для ролей при N, либо готовый `manifest.json` с ролями.
Без ключа Ollama положите рядом с EPUB файл `ИмяКниги.roles.json` (готовый manifest
для того же исходного EPUB) или передайте `--roles-manifest /путь/manifest.json`.
При отсутствии обоих скрипт остановится, а не заменит персонажей рассказчиком.
Ключ не сохраняется. Облачной модели отправляется текст; учитывайте приватность.

При запуске проверяются зависимости, словари, музыка и две модели.
Сначала проверяется собственная `models`, потом уже установленные модели в
`../models`. Найденные модели копируются в собственную `models` (APFS-копии
без ссылок наружу). Если моделей нет, они автоматически скачиваются туда же.
Частичные загрузки возобновляются; повреждённые готовые файлы не перезаписываются
молча. Модели: Ru-Stress-CF **исходные веса**, VoiceDesign **MLX 8-bit**.
Для скачивания нужен интернет; модели, окружения и полный бинарный словарь
не включены в GitHub. На другом Mac нужны Homebrew Python 3.11 и FFmpeg:
`brew install python@3.11 ffmpeg`. Остальные пакеты устанавливаются автоматически
в `.venv-mlx` и `.venv-stress` рядом со скриптами. На этом ноутбуке всё уже собрано.

Каждый запуск создаёт отдельную папку с названием книги и датой. В ней:

- `result/book.m4b` — аудиокнига с главами;
- `result/book-read-along.epub` — текст + встроенное аудио, подсветка предложений;
- `audio-music/sample.mp3` — быстро послушать (откроется в QuickTime);
- `audio-normalized/sample.mp3` — та же речь **без музыки**;
- `source/book-stressed.txt` — текст озвучки с ударениями;
- `source/stress-arbitration.json` — решения LLM, если она включена;
- `run.log` — журнал этапов.

Музыка: первый трек MyTTS «Свет лампы и страницы». Зацикливается на всю книгу
после нормализации речи. Громкость — линейные 5% (коэффициент 0,05), речь остаётся
с коэффициентом 1. Паузы и длительность не меняются; этот же микс попадает в M4B
и EPUB. EPUB с синхронным аудио проверяйте в читалке с поддержкой EPUB3 Media
Overlays (например Thorium); стандартный просмотр EPUB не гарантирует подсветку.

VoiceDesign создаёт один образец на роль, затем завершается; после него Base
озвучивает все реплики с этим образцом. Обе модели одновременно не загружаются.
Образцы удаляются после запуска. После синтеза завершается процесс модели,
затем работают только обработка аудио и сборка файлов. Не запускайте две книги
параллельно: последовательный запуск экономит память M2 Pro.

Точность ударений и ролей не гарантируется. Если LLM не смогла выбрать говорящего,
сборка останавливается с `roles-review.json`, а не назначает персонажа наугад.
Длительность теста приблизительная: ради ровных 300 секунд фразы не обрезаются.

Из Terminal также можно передать два пути:

```sh
./START.command "/путь/Книга.epub" "/путь/Результаты"
./START-5MIN.command "/путь/Книга.epub" "/путь/Результаты"
```

С готовыми ролями без обращения к Ollama:

```sh
./START.command "/путь/Книга.epub" "/путь/Результаты" --roles-manifest "/путь/manifest.json"
```

Выберите N. Для проверки только текста добавьте `--prepare-only` — TTS не загрузится.

# Повтор прежнего отрывка: около 7 минут

Запускайте `TEST-7MIN.command`. Он сохраняет конец прежнего пятиминутного
отрывка и добавляет начало: абзацы p00049–p00097 вместо p00058–p00097.
Длительность приблизительная: итог зависит от темпа модели. Музыка зациклена на 5%,
роли сохраняются, ударения — словарь + Silero, облачная проверка спорных мест по Y/N.
N отключает только проверку ударений LLM, не многоголосность.
Каждый запуск сохраняется в отдельную папку `results/test-7min-ДАТА-ВРЕМЯ`.

В локальном комплекте исходные роли и измерения находятся в `demo`.
Текст книги не включается в публичный репозиторий. Для исходников с GitHub
передайте пути: `./TEST-7MIN.command /путь/manifest.json /путь/timeline.json`.
