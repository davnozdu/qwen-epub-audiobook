# Qwen EPUB Audiobook

Подготовка русских EPUB по ролям, локальная озвучка Qwen3-TTS 1.7B на Apple Silicon,
отдельная аудиокнига M4B и EPUB 3 со встроенным аудио и подсветкой текущего предложения.

В репозитории только исходники и тесты. Книги, аудио, веса моделей, кэши,
окружения Python и API-ключи не публикуются. Проект вырос из работы над
[mytts-books](https://github.com/davnozdu/mytts-books).

## Как работает

1. `prepare_qwen.py`: LLM определяет говорящих, пол, возраст и индивидуальные
   описания голосов. Нарезка сохраняет текст, роли и привязки к исходному EPUB.
2. `audiobook_epub.py prepare`: создаёт отдельный EPUB и его манифест. Режим
   `--highlight sentence` дополнительно делит текст на предложения через Razdel.
3. `prepare_speech.py`: после окончательной нарезки и определения ролей раскрывает
   числа, даты, годы, время, главы, единицы, дроби, телефоны и сокращения. Затем
   Сначала словари Supertonic ставят ударения/ё, затем DeepSeek проверяет их
   по контексту и дополняет неизвестные слова и необходимую пунктуацию.
   Исходный `text` остаётся для EPUB, отдельный `tts_text` — для синтеза.
4. `synthesize_qwen_mlx.py`: VoiceDesign создаёт по одному образцу каждой роли,
   выгружается и освобождает кэш, затем Base озвучивает весь текст по образцам.
5. `audiobook_epub.py package`: EbookLib собирает EPUB Media Overlays, FFmpeg — M4B
   с главами. SMIL связывает текст с реально измеренными интервалами аудио.

Пол и голос — разные задачи: корректная метка `female` не гарантирует звучание.
Образцы и результат нужно прослушать. Для каждой роли свои описание и seed;
постоянство обеспечивается одним аудиообразцом на роль внутри запуска.

## Установка на macOS / M2 Pro

Проверено на M2 Pro, 16 ГБ памяти, Python 3.11 arm64. Требуется доступ к Metal.

```sh
brew install python@3.11 ffmpeg
python3.11 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

Скачайте VoiceDesign 8-bit и исходный Ru-Stress-CF (без конвертации):

```sh
.venv/bin/hf download mlx-community/Qwen3-TTS-12Hz-1.7B-VoiceDesign-8bit \
  --revision f90d617701d9f7f4ca499291e0b57f2b3c2fd2ee \
  --local-dir models/Qwen3-TTS-12Hz-1.7B-VoiceDesign-8bit
.venv/bin/python setup_stress_qwen.py download
```

Скрипты используют `/opt/homebrew/bin/ffmpeg` и `ffprobe` (Homebrew arm64).
Лимит MLX — 8 ГиБ, кэша — 512 МиБ. Настройки памяти GPU macOS не изменяются.
Во время синтеза сетевые загрузки моделей отключены.

## Подготовка своей книги

```sh
.venv/bin/python prepare_qwen.py run book.epub -o work/prepared \
  --model deepseek-v4.1-flash --no-think
```

Ключ Ollama вводится скрыто при запросе либо передаётся через `OLLAMA_API_KEY`.
Не сохраняйте ключ в репозитории. Подготовка отправляет текст книги в облачную
LLM — используйте этот режим только для книг, которые разрешено туда передавать.
Модель и доступность облачного сервиса определяются вашей учётной записью.
Роли можно исправить через `--cast` и `--roles-overrides`.
Есть файловый возобновляемый режим `advance` и проверка `check`.

## Пять минут как самостоятельная мини-книга

```sh
.venv/bin/python audiobook_epub.py prepare \
  --manifest work/prepared/manifest.json --seconds 300 \
  --start-paragraph p00001 --highlight sentence --out work/source
./run.command
```

Без предыдущего таймлайна длительность оценивается по 14 символам/с. При наличии
измерений можно добавить `--timing previous/audio/timeline.json`. Вырезаются только
полные абзацы. Новое аудио может оказаться длиннее или короче пяти минут.
Мини-книга озвучивается целиком (`--whole-book`), а не обрывается по таймеру.

## Вся книга

```sh
.venv/bin/python audiobook_epub.py prepare \
  --manifest work/prepared/manifest.json --highlight sentence --out work/source
./run.command
```

Можно использовать отдельный каталог проекта: `./run.command another-project`,
если в нём есть `source/manifest.json`. Одна команда запускает синтез, затем
упаковку; при ошибке синтеза упаковка не выполняется.

Результаты в `work/result/`:

- `book.m4b` — аудиокнига AAC 128 кбит/с с метаданными и главами;
- `book-read-along.epub` — текст, встроенное аудио и подсветка;
- `package-report.json` — результаты проверки.

В `work/audio/` сохраняются WAV фрагментов, полный WAV/MP3, `timeline.json`,
`benchmark.json`. `work/run.log` — общий журнал. Повторный запуск обновляет результаты.
Для прослушивания EPUB с подсветкой подходит [Thorium Reader](https://www.thoriumreader.com/).

## Подсветка и память

`--highlight sentence` — режим по умолчанию. Каждое предложение озвучивается
отдельно, подсвечивается по реальным границам WAV. Если предложение пересекает
границу роли или прежнего лимита длины TTS, оно остаётся разделённым на части.
`--highlight fragment` сохраняет прежние более крупные фрагменты.
Подсветка отдельных слов не реализована: для неё нужно отдельное выравнивание.

Launcher использует временные образцы (`--ephemeral-voices`): они создаются заново
и удаляются после успеха, ошибки или обычного прерывания. Старые библиотеки не
импортируются. VoiceDesign и Base не загружаются одновременно; при выходе модели
освобождаются и MLX-кэш очищается. Завершение процесса возвращает оставшиеся
ресурсы ОС. SIGKILL/отключение питания могут оставить временные файлы.
Для постоянной библиотеки при прямом вызове генератора уберите `--ephemeral-voices`.

## Проверки и ограничения

```sh
.venv/bin/python -m unittest discover -s tests -v
```

Проверяются сохранность текста/пробелов/ролей, границы предложений, таймлайн,
встроенное аудио, SMIL, CSS подсветки и реальная сборка тестового M4B через FFmpeg.
MLX-тесты используют имитацию GPU; качество голоса требует отдельного аудиопрогона.
Это не заменяет EPUBCheck и проверку в конкретной читалке.

Исходный EPUB не меняется. Создаётся редакция с простым оформлением, без исходных
обложек, шрифтов и внутритекстовой разметки. Поддерживаются текстовые листовые блоки;
неподдерживаемая структура останавливает подготовку, чтобы не потерять текст.
EPUB Media Overlays должны
поддерживаться читалкой; обычная читалка покажет только текст.
Аудио полной книги собирается потоково с диска, без удержания всей записи в RAM.

Старый EPUB без подключённого CSS можно исправить без повторной озвучки:

```sh
.venv/bin/python audiobook_epub.py repair-highlight \
  --epub old.epub --out highlighted.epub
```

Основа: [EbookLib](https://github.com/aerkalov/ebooklib),
[MLX-Audio](https://github.com/Blaizzy/mlx-audio),
[Qwen Design then Clone](https://github.com/QwenLM/Qwen3-TTS#voice-design-then-clone),
[Razdel](https://github.com/natasha/razdel), [FFmpeg](https://github.com/FFmpeg/FFmpeg).
См. [THIRD_PARTY.md](THIRD_PARTY.md) перед распространением производных проектов.

## Нормализация и ударения из Supertonic

`run.command` автоматически запускает подготовку речи **до загрузки обеих TTS-моделей**.
DeepSeek через Ollama по умолчанию работает без рассуждений, запросы последовательные,
пакеты по 2400 знаков. API-ключ вводится скрыто; в файлы и журнал он не записывается.
Успешные ответы кэшируются. Некорректные ответы повторяются до трёх раз; при отказе
проверок озвучка не начинается, исходный манифест не заменяется частично готовым.

Отдельный запуск только подготовки текста:

```sh
.venv/bin/python prepare_speech.py run --manifest work/source/manifest.json
.venv/bin/python prepare_speech.py check --manifest work/source/manifest.json
```

Применяется промпт Supertonic из `LlmProviders.kt`, таблицы падежей/порядковых
числительных, адаптированные алгоритмы `RussianBookNormalizer`,
`RussianNumberNormalizer`, `RussianDates`, обработка пробелов и сокращений.
SHA-256 исходных файлов сохранены в `supertonic_rules.json`. Обработчик написан на
Python: JVM/Android для Mac не нужны. Учёт уже поставленных ударений в именах
предотвращает смену произношения той же словоформы между пакетами.

Проверки отвергают добавленные/потерянные слова, изменённые числовые значения,
кавычки, дефисы, некорректные отметки ударения и смену исходных ролей/привязок.
Небольшие подмены слов LLM восстанавливаются из исходного текста без угадывания
ударения; добавление/потеря слов и изменение числовых значений не принимаются.
Пропущенные ударения допустимы: слово передаётся Qwen без отметки, без повторных
запросов на дополнение ударений и без остановки книги.
Неподдерживаемые/некорректные числовые форматы останавливают подготовку для
ручной проверки. Это не гарантирует безошибочной орфоэпии LLM — нужен слуховой тест.
После нового деления на предложения подготовка речи выполняется заново;
старый текст озвучки не наследуется новым фрагментом.

Ударение кодируется Unicode U+0301 после гласной. Воздействие этих отметок на
конкретный checkpoint Qwen необходимо оценить на слух. Если он читает их хуже,
прямой вызов генератора поддерживает `--stress-marks strip` (нормализация и ё
сохраняются). По умолчанию отметки передаются модели.

Словари необходимо один раз импортировать из пользовательского Supertonic:

```sh
.venv/bin/python import_supertonic_dictionaries.py --source /path/to/supertonic
```

Импортируются статические исключения Silero, системные поправки, `stress_fixes`,
список омографов, контекстные фразы, однозначные грамматические варианты и
безопасные правила первых частей сложных слов. Они хранятся в `data/stress/`
и не публикуются в Git. `--dictionary-dir` позволяет указать другой каталог.
Существующие авторские ударения сохраняются. Неоднозначные словарные варианты
без подходящей контекстной фразы не выбираются наугад — их проверяет LLM.

`prepare_speech.py offline` выполняет нормализацию и словарные ударения **без LLM**.
Android/JNI и нейронный Silero Stress/BERT не перенесены и не загружаются.
Статические словари не покрывают все словоформы: неизвестные слова дополняет LLM,
а оставшиеся без отметки произносит Qwen. Автоматическая проверка не гарантирует
безошибочность каждого ударения.

Полный бинарный словарь [russian-v1.1](https://github.com/davnozdu/supertonic-dictionaries/releases/tag/russian-v1.1)
подключается автоматически из `data/stress/russian_accents_full.sacc`.
Скрипт проверяет размер 179200764 байта и закреплённый SHA-256, затем использует
read-only `mmap` и двоичный поиск по UTF-8-ключам вместо загрузки 179 МБ в Python-словарь.
`max8`/`max9` — сокращённые альтернативы того же словаря; одновременно с полным
они не нужны. Данные не публикуются в Git. После подключения полного словаря
кэш подготовки обновляется; LLM может исправить предложенное словарём ударение
по контексту, но не авторское.
Английский `CurrencyNormalizer` намеренно не применяется к русской книге.

## Рабочий тест книги через rab

Запуск: `../run-book-rab.command`. Он готовит прежний примерно пятиминутный
фрагмент (p00058–p00097), нормализует текст и ставит ударения из бинарного
словаря без LLM. `export_rab_text.py` объединяет речевые предложения обратно
в абзацы, не добавляя имена ролей в читаемый текст.

Озвучку выполняет пользовательский `../rab/qwen_tts_stress.py` без изменений:
обычный mlx-audio, локальные исходные веса Ru-Stress-CF, образец Milena через
macOS say, температура 0.9 и куски до 250 символов. Наши ICL/EOS-адаптеры
отключены и удалены из проекта. В этом тесте один голос, не отдельные роли.
Результаты: `../book-test-rab/source/book-stressed.txt`, исходный текстовый
EPUB, общий `audio/book-test.wav` и отдельные WAV-куски. Точный хронометраж
зависит от нового голоса; оценка пяти минут взята из предыдущей записи.
Это пока WAV-проверка, без M4B и синхронизированного аудио-EPUB.
Завершение отдельного процесса освобождает память модели. Незнакомые слова
и неразрешённые омографы остаются без добавленного ударения.

Для полной цепочки короткого фрагмента в текущем QwenTTS запускайте
`./run-book-test.command` (или прежний `../run-book-test.command`):
прежние четыре роли → предложения → нормализация и бинарные словари →
контроль LLM (Ollama, без размышлений) → VoiceDesign → Ru-Stress-CF → M4B и
EPUB с подсветкой предложений. Используется исходный чекпойнт, как в рабочем
rab-тесте, не 8-bit конверсия. Ввод API-ключа интерактивный, ключ не сохраняется.
Озвучка с `--rab-generation` использует массив образца, температуру 0.9,
нативные настройки сэмплера и функцию деления включённого `rab/qwen_tts_stress.py` до 250
символов; лимит аудиотокенов остаётся защитой от бесконечной генерации.
Части длинного предложения остаются одним якорем EPUB. Ни ICL, ни EOS
не патчатся. Короткий образец на каждую роль создаётся один раз за запуск,
используется для всех её реплик и удаляется в конце теста. VoiceDesign и Base
загружаются последовательно. Результаты отдельно: `../book-test-rab-roles/`.
Точная длительность новой озвучки может отличаться от оценки пяти минут.
Для другой книги подготовьте `work/source/manifest.json` по инструкции выше
и запустите `./run.command [папка-проекта]`: он выполняет ту же рабочую цепочку.
`run-book-test.command` использует прежние локальные манифест и таймлайн из
QwenTTS — книга и её данные не включены в репозиторий.
